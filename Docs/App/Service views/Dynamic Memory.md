Access to all avaliable dynamic blocks
Automatically refreshes the visible view (0.5s)
### Appbar
- (right) Current/Backup view
- Save button (current) /Recall button (backup)
- Refresh button (with autorefresh function, opens a selection window, has a green dot if active)

### Main view
- List containing nested lists
	- Main list entries show block name, block type and flags
	- Sublist contain block's entries
		- Show type and flags and value of each entry
- Values and blocks can be edited when tapped (current); an entry's popup menu offers Edit value / Change type / Delete
- Block Save (current) / Recall (backup) via the appbar; the backup view shows a per-entry Recall button
- Show value entry names and units based on the value and block types, enums and indexes.
