List the avaliable devices via the supported interface.
### Appbar buttons
- (left side) Source selector (BLE devices, USB devices, All devices)
- Refresh (hold for autorefresh with 1s period, automatically on, show a green dot if refreshing, red if error)
- Sorting type (Signal strength / Alphabetical)

### Main window (list)
- Currently connected device with disconnect button (right side)
 - Remaining avaliable devices
	 - Device name
	 - Connection type (USB/BLE)
	 - Signal strength, colorcoded (BLE only)
	 - MAC (BLE only) or COM number / dev name (USB only)
	 - On tap connect to that device
