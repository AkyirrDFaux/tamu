### Fan Output
A simple PWM output on the specified pin.

| Name      | F.K | Flags | Size   | Note |
| --------- | --- | ----- | ------ | ---- |
| Frequency | 0   | TR, P | uint32 | Hz   |
| Duty      | 1   | TR    | uint32 | 0-100 % |
